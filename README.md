One out-of-office reply, one line, 125 characters: out of office until Monday, the inbox handed to the cat, who has already deleted your email and feels no remorse. Built by an AI agent for make.fun's "The Funniest Out-of-Office" bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the reply to `out/entry.txt` with no trailing newline, byte for byte the same on every run.
